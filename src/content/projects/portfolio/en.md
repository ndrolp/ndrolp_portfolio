## The goal

Create a fast, clear personal space to present my professional journey as a Full Stack Developer. The site puts experience, technologies, and a direct contact path first.

## The solution

The portfolio is built with Astro and localized Markdown content. Experience sections are powered by JSON data, while project content is organized by language, so a new case study only needs matching Spanish and English Markdown files.

## Features

- Responsive interface using the Catppuccin Mocha palette.
- Persistent Spanish and English language selector.
- Professional experience structured from JSON.
- Localized projects rendered from Markdown.
